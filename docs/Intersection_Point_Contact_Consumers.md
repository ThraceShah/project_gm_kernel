# 有限面点接触的实体消费者

## 事件与材料语义

已有 `ConvexPlaneContacts` 的区间 Hessian 认证能证明强凸/强凹 NURBS 与平面的唯一内部驻点接触。新增输出保留证明时得到的真实 UV，不再通过全局反求重建 preimage。实体布尔将 `PointContact` 和双 UV 与普通交线分别缓存，再用两个真实有限面的环裁剪接触点。它不是无交的空图。

当前支持没有其它体积交叠的内部面点外接：交集为空，差集保留实体并在接触面插入独立顶点环。真实 PK 对应结果也有额外顶点及一个 edge=null 的 fin/loop；“没有体积交叠”不能推导为原 B-rep 字节不变。并集的点连接拓扑、内部相切空腔和接触点落在有限面边界上的情形尚未表示，明确返回 `PK_ERROR_not_implemented`。

顶点环复用现有 `AddDegenerateFinToLoopAndVertex`，没有新增记录字段或 ABI。追加前保存拓扑及几何的 before-image；随后重建几何所有权和点链，发布拓扑 tag 并丢弃旧 XT 缓存。有限域面积排列忽略顶点环的零维贡献，但保留其顶点供点分类与边分裂使用。后续布尔重建将保留的源顶点环转移到包含它的结果单元；若它已成为结果边上的顶点，不重复插入顶点环。

## 有限域分离证据

某些支撑面的自然延续存在交线，有限面却与平面分离。新增自然域证书要求非周期夹持 NURBS 的四条完整边精确对应其四条自然参数边，可包括反向及整体齐次缩放。只有通过此证书的面才用整个自然参数矩形作为有限面的包围超集。任意裁剪环、ICurve 边或未证明的域外延续不能借用该证书。

对该完整矩形的每个 Bezier patch，使用向外舍入的空间区间投影到平面法向，必要时细分，证明全部区间同侧且超出请求容差。区间不确定、深度或预算耗尽继续原求交路径，不返回伪空交集。所有判定使用几何定义与区间证据，没有模型名、tag 或坐标分支。

几何平面 NURBS 若参数映射并非仿射，实体裁剪保留真实 NURBS 作为 ICurve 支撑；不能仅凭空间交线为直线就替换成两个代理平面的 Line。这一差异通过后续切削的真实 PK 类型比较发现。

## 验证入口

- `tests/KernelTests/ContactSupportCutTests.cs`：点与空关系、双支持参数、容量失败。
- `tests/KernelTests/ContactBooleanConsumerTests.cs`：差交、保存重载、接触顶点分类、不支持并集的原子拒绝及六档分配故障。
- `scripts/ExteriorContactBooleanOracle.cs`：制造族 `z=.5+x²+y²` 与平面 `.5+h`，负 h 无交、零 h 孤立点、正 h 完整闭环；分别执行真实 PK 和自研 SSI 及差交，检查完整分支、text XT 接收、完整 BODY_check、结构/region-shell/type/sense/容差/missing 和 PK 物性。

零高度结果另外执行自研 XT 重载后的实际侧向切削，再复制、镜像缩放及重载，并保留接触顶点环。以上各结果均通过完整 PK BODY_check 及包括 loop 数、类型、sense、容差、region/shell 的结构硬条件。未通过的事件或极细近切范围不混入这三组已验收事件。

本轮 Release 定向测试 73/73，通过上述分配、分类与生命周期回归及原有规则曲面/解析布尔测试。真实 PK 三个高度的 SSI、六个布尔与后续切削/镜像链全部通过；既有规则曲面/同域 oracle 39/39 通过。

本工作没有修改 C ABI，验证使用托管 Release 及真实 PK，没有执行 NativeAOT 发布。
