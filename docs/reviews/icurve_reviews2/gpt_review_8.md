2. 为什么附件中“叉乘会精确消去巨大轴向分量”的解释不成立

附件用下面的理由支持新守卫：

> 叉乘操作会精确消去沿轴的巨大分量。



这个说法只在精确实数运算中成立，不能直接用于当前普通 binary64 叉积。

对上述 \(P_1\)，Z 分量的精确计算是：

\[
\begin{aligned}
M_z
&=(3L+4)\cdot4-(4L+4)\cdot3\\
&=(12L+16)-(12L+12)\\
&=4.
\end{aligned}
\]

两个精确乘积分别为：

54043195528445968
54043195528445964

这一数量级的 double 间距为 8。当前普通乘法把第二个乘积舍入成第一个，于是实际执行的是：

54043195528445968 - 54043195528445968 = 0

局部轴点的矩则是小数值计算：

4*4 - 4*3 = 4

最终得到：

\[
\widehat M_{\rm local}-\widehat M_{\rm orig}
=(0,0,4),
\]

把原轴矩的计算误差误认为了局部轴的几何漂移。

这类“两个乘积之差接近零”的计算，正是几何谓词需要误差过滤、补偿或更高精度后备的典型原因，不能仅凭代数消去关系认定浮点结果可靠。

为什么现有回归没有发现它

当前新增倾斜轴测试的原点是 (0,0,0)，远参考点是 \(LA\)，原轴矩恰好为零。这覆盖了上轮具体反例，但没有覆盖非零轴矩被巨大乘积相减吞掉的情况。两个 Z 轴控制同样不会触发这种消减。

因此，本轮新增的整体平移不是任意扩大测试范围，而是检查这项守卫是否满足它所依赖的轴线表示不变性。

3. 建议修复：保留 FMA 重定位，不再用未经误差控制的矩差裁决

首选方向：直接利用 FMA 构造本身的误差

当前采用未归一化的原始轴向量 A构造：

\[
\widehat P_{\rm local}
=\operatorname{FMA}(A,t,P).
\]

这里存在一个可以利用的性质：

无论计算出的有限 double 参数 t 是否等于精确投影参数，在精确实数意义下，\(P+tA\) 都位于原始轴线上。 t 的误差会影响局部化效果，但本身只改变沿轴位置。

设逐分量 FMA 的最终舍入误差为 e：

\[
\widehat P_{\rm local}=P+tA+e.
\]

那么新点离原轴的垂直距离满足：

\[
\delta_{\rm axis}
=\left\|
\left(I-\frac{AA^T}{A\cdot A}\right)e
\right\|
\le \|e\|.
\]

这是对当前构造方式的直接推导。Math.FusedMultiplyAdd 的契约是乘法和加法视为一个三元运算，只在最终结果处舍入；它不同于先舍入乘积、再做加法。

因此可以：

保留原始 A、t 和 FMA 结果，为每个分量建立保守的最终舍入界，再合并成轴漂移上界。 需要更紧结果时，保存仿射运算的低位误差，而不是重新计算两个容易消减的巨大矩向量。

本轮反例中，精确有理数核对得到三个 FMA 构造误差全部为零。即便使用输出附近可表示间距给出保守界，尺度也只是约 \(10^{-15}\)，不会虚构出 0.8 的轴偏移。

这条方案的边界也必须写清楚：

检查 A、t、FMA 输出及相关尺度有限；

舍入界的组合应保守，包含极小数与边界情况；

后续径向投影、残差和角度计算仍有自己的误差，不能因为局部轴点通过检查，就宣称整个求值已被严格认证。


这是一条修复方向，不是本轮已经提交或运行过的生产补丁。

备选方向：保留 Plücker 检查，但完整计算其数值误差

若希望继续用矩一致性作独立验证，应对每个分量：

\[
ab-cd
\]

采用受控的乘积差计算，并将低位和误差继续传到：

原轴矩
→ 局部轴矩
→ 两矩之差
→ 距离及阈值比较

本轮公式级试验中，用 FMA 恢复乘积舍入低位，能够把该例的原轴矩 Z 分量恢复为 4。但仅修复一个分量的乘积差，不等于整个守卫已经具有可靠误差界。

不要简单采用以下替代方式：

放大漂移阈值。 它只是让错误的 0.64 被放行，也可能同时放过真实漂移。

删除全部漂移验证。 上轮证明过局部坐标构造确实可能改变轴，验证需求仍然存在。

先算 localAxisPoint - axisPoint，再直接叉乘。 这一步本身也可能丢失小的横向分量，仍需分析误差，不能因为表达式更短就视为稳定。

两种方案都应抽成供 SpunConstraints 和 TryRecoverSpunAngle 共用的局部轴准备函数，避免两个入口的判断再次分叉。
