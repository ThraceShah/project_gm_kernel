## 1. [P2，Spun 数值回归] 重建局部轴点时的大数消减，实际移动了旋转轴

**位置：**


然后以 `localAxisPoint` 为参考计算径向分量。这个思路解决了上轮精确 Z 轴的轴向距离阈值问题，但目前把**经过浮点运算重建的局部轴点**直接当成了原轴上的精确点。

对于倾斜轴，方向归一化误差、大数相减及乘加舍入会使这个点偏离原轴；后续计算便围绕一条已经移动的轴进行。两个函数都存在相同路径。

### 一个全部输入均可精确表示的反例

定义：

```text
axis              A = (3, 4, 0)
profilePoint      C = (-4, 3, 0)
profileDerivative   = (3, 4, 0)
point             x = (0, 0, 5)

L = 2^52 = 4503599627370496
```

比较两个轴参考点：

\[
P_0=(0,0,0),\qquad P_1=(3L,4L,0).
\]

它们满足：

\[
P_1-P_0=LA,
\]

所以表示的是**完全相同的一条轴线**。上述输入都可精确表示为 binary64。

几何关系也不需要数值求根：

\[
A\cdot C=A\cdot x=0,\qquad \|C\|=\|x\|=5.
\]

x 正好是 C 绕 A 正向旋转 \(\pi/2\) 后的点。因此正确结果是：

\[
h_1=0,\qquad h_2=0,\qquad
\nabla_xh_2=(0,0,10),\qquad \theta=\pi/2.
\]

### 当前实现的独立复算结果

按当前 `EvaluationMath` 的标量运算顺序重放，没有使用替代的向量化计算或融合求和。

| 检查项 | 使用 \(P_0\) | 使用 \(P_1\) |
|---|---:|---:|
| 重建的 `localAxisPoint` | `(0,0,0)` | **`(-2,0,0)`** |
| `SpunConstraints` 状态 | `Success` | **`Success`** |
| 轴向残差 | `0` | `0` |
| 径向平方残差 | `0` | **`15.999999999999996`** |
| 径向残差对 x 的梯度 | `(0,0,10)` | **`(2.56,-1.92,10)`** |
| 恢复角度 | `1.5707963267948966` | **`1.8804992713373527`** |

恢复角度误差为：

\[
0.3097029445\ \text{rad}\approx17.7447^\circ.
\]

精确有理数计算表明，两种表示下正确的局部轴点都是 `(0,0,0)`。当前算出的 `(-2,0,0)` 不在原轴上；通过它建立的平行轴与原轴距离为 **1.6**。

**这不是“两个参考点对应不同几何”，也不是未知旋转角的周期歧义，而是局部化计算改变了正在求值的轴。**

同一输入按父提交的公式重放会返回 `Singular`；本次重定位后，局部坐标变小，旧的拒绝条件不再触发，却没有保留重定位过程已经产生的误差，转而返回了错误的残差和角度。

需要限定影响范围：这里的 `Success` 是**内部约束及角度恢复辅助函数**的返回结果。本轮没有执行完整 Spun／ICurve 求根，也不据此声称公开 API 已返回错误交点。

### 修复意见

**应保留局部化方向，但不能把不稳定地重建世界坐标点当成无误差的坐标变换。**

建议将轴线的稳定表示或局部 frame 准备集中处理，使用带补偿／误差传播的投影与仿射运算，避免每次先计算两个巨大世界坐标量的差，再把结果当成精确局部原点。仅将最后一次加法换成 FMA，并不能自动消除前面的方向归一化、减法和点积误差。

同时，误差评估必须覆盖**原始轴点到局部轴点的构造过程**。当前的局部 `zc` 已经接近零，它不能反映此前损失了多少径向信息。若暂时无法可靠保持原轴，应明确返回数值失败，而不是继续输出错误的约束值；这与真正的“点位于旋转轴上”应当区分。

回归应同时检查：

- 同一轴线的两个参考点，得到相同的约束、梯度及旋转角；
- 本例的闭式值，而不仅是两条实现路径相互比较；
- 上轮已经修好的 Z 轴大坐标输入继续成功，不能通过一律拒绝大坐标来解决。

这项属于对规格 §9.4 中既定旋转轴几何的求值保真问题，不需要修改双约束本身。
