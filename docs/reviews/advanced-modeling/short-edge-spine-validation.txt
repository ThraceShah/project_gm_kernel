Implemented public geometry/transport repairs

1. XtReader.Brep accepts a curve-valued BLENDED_EDGE spine instead of requiring
   INTERSECTION. Its runtime compiler now implements Line/Circle/Ellipse maps.
   Unsupported representations are not counted as new support.
2. ParametricSpineCurve / SpineParameterMap centralise exact native-parameter
   position, tangent, Taylor coefficients, interval equations and the station
   gauge. The joint solver, derivative solver, interval solver and series
   evaluator use this common map. Explicit curves are not converted to CHART
   parameterisation. Witness subdivisions are inverse-search seeds only.
   Complete natural periodic conics keep Help-domain periodic lifting; true
   finite LIMITs retain their own endpoints. Nearest-foot orientation tests
   use the live gauge gradient, including interval gradients, rather than a
   witness tangent that can turn through an obtuse angle on an eccentric
   ellipse within one seed interval.
3. Complete analytic coefficient bounds certify these curves against signed
   offset Plane/Cylinder/Sphere supports; wrong-radius/shifted same-topology
   curves have negative tests. These certificates are not sampled clearance,
   reach or general self-intersection proofs. Regular local tubes still use
   the existing interval/Krawczyk machinery and deterministic failure contract.
4. BLENDED_EDGE fields 17/18 preserve actual T LIMIT records with one hvec
   each. Import recovers the native finite parameter interval, including a
   periodic lift, and stores the real limit payload. Fresh writing, deep copy,
   similarity transformation, undo and deletion maintain that payload.
   Fields 15/16 and other LIMIT layouts remain outside this addition.
5. Similarity transport updates the compiled explicit map. Line parameters
   scale with spatial scale; angular parameters retain their native values.
   Intersection UV records are transported into the canonical periodic chart.
   Without this correction the reflected seed's fresh XT had a cylinder face
   with PK_FACE_state_bad_loops_c, despite strict compare reporting no diffs.
   PK's independently transformed body and its own XT roundtrip both passed.
   After the correction all three full checks and strict compare pass.

There is no filename, tag, coordinate, radius or seed-template dispatch in

Ownership repair

A new public Boolean regression uses contained spheres with construction
offset surfaces on both input bodies. Before the fix, ReplaceProfileBody
swapped body records without changing construction owner tags. Deleting old
topology then unlinked the wrong body's chain repeatedly and exhausted undo
memory (OutOfMemoryException in DeleteBodyCascade/TryGrowUndo).

ReplaceProfileBody now snapshots both construction chains before mutation,
then rebinds their owners along with the topology before deleting the old
body. The regression verifies the surviving owner, deletion, mark restoration
and cleanup. Seven allocation-failure budgets check atomic rollback and return
memory. Existing construction/transform capabilities were retained.
