Public numerical fixes

1. A rolling section with coincident contacts has a removable zero-angle
   limit. Previously normalising the transverse contact vector rejected that
   limit. RollingSectionEvaluation now evaluates spherical interpolation
   through its analytic power series near that limit, including rectangular
   mixed D2 derivatives. Its independent interval recurrence bounds the
   complete remaining tail and its derivative. It also encloses small
   extension boxes needed for endpoint root certificates. No polyline or
   fixed spatial sample set supplies the certificate.

2. An explicit spine occurrence now imposes P=E(t) in the joint scalar,
   Taylor and interval systems. It does not reconstruct E from two offset
   gradients that can become dependent at a legitimate terminator. Its exact
   tangent defines the nearest-station equation. Scalar and interval Schur
   tests retain the local distance-minimum test. This does not establish
   global reach for arbitrary new representations. Exact explicit root
   evaluation and bounds use the same native curve descriptor. Real T limits
   remain in public evaluation, finite patch domains, XT and ownership data;
   internal bounds also enclose mathematical extensions for root proofs.

3. AnalyticSpineContact describes the exact affine image of a conic/line
   spine on a plane, sphere or cylinder. Recognition compares full curve
   coefficients, with finite parameter scaling for lines. It supports phase
   changes and reversal. Boundary rays can use the resulting contact station
   rather than rediscovering an already known contact. Runtime descriptor
   extraction is shared with the existing compiler.

4. A finite ICurve can be compiled with its original CHART map and support
   dependencies, and bounded by the existing implicit interval tube. Both
   short seed ICurves obtain finite certificates. Plane intersections can
   reuse the existing scalar interval root solver on that actual finite
   curve. Failed certification retains the prior surface-intersection path;
   it is never reported as proven empty. In particular the long blend seam
   still has unresolved certification boxes.

Production selection depends on geometry representations and certified
relations, not filenames, identifiers, coordinates, radii, edge counts or
seed topology. These changes do not implement a new B-rep assembly system.
No seed-specific construction or fast-path template was added.

Precision evidence and performance boundaries

The diagnostics finish every classification before issuing additional range
and projection queries. Interleaving these diagnostics caused one PK
exact-threshold result to change, so that run is not the replay baseline.
For each remaining failure the final log includes the exact input coordinate,
nearest PK face/edge/vertex for each native representation, closest vector,
UV, oriented face normal, signed local residual and actual edge/vertex
precision. The original CSV is not rewritten.

PK_TOPOL_range_vector can report distance zero for a point whose returned
closest vector is spatially separated. Therefore diagnostics retain both
PK_distance and the recomputed spatial_distance; they do not treat the
toleranced zero as mathematical equality. For example saved row 50 has
point (-1.5,-2,5.00000001), spatial distance 9.99999993922529e-9 and
edge/vertex precision 5e-9. PK original, native roundtrip and managed-fresh
PK result classify outside; managed import classifies on. No precision was
increased and this mismatch is still a failure. Its full policy cause is
not yet established.

The existing five-case oracle separately records full FixBlends and Boolean
times. This run's managed FixBlends range was 0.542--5.592 seconds, Boolean
2.464--45.153 seconds. Other verification jobs ran concurrently, so these
are observations, not an isolated performance comparison or speed claim.
The seed's failing FixBlends took 40.857ms; its failing subsequent Boolean
took 12.109s and progressed farther than before. Neither is a successful
modeling performance acceptance result. Hot D2 zero-allocation checks do
not substitute for those complete operations.
