## 4. Parasolid 研究合同

恢复后使用 `parasolid-research`、`parasolid-docs` 和 `parasolid-query` MCP。每次实验前记录：

优先找真实执行路径上决定输出的条件，核实输入、返回值及对应的拓扑变化，再推导可验证的通用规则。调用命中、符号相似和反编译分支本身都不是行为证据。遇到残缺条件、寄存器伪代码或可疑类型时，以汇编和真实 GDB 执行核实；检查断点实际地址、调用约定及返回寄存器。失败或错误绑定的断点数据不得用于结论。查询应回答具体问题，缓存已有结论，避免重复查询未变信息或漫游调用图。
