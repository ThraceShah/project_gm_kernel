# M3–M5：求交事件、局部拓扑和建模性能的共同设计

基线：M2 `cd01bdb`。本轮同时推进原计划 M3、M4、M5，不以模型名称、固定坐标、
实体 tag 或验收参数识别输入。精确解析降维、等半径三价角点和同域证明属于可验证
的几何/拓扑类别，必须在该类别的变换及参数族上验证，不能只匹配一个构造实例。

## 共享合同

### 几何结果与事件

`SurfaceIntersectionNode` 已携带空间点和两侧 UV，`SurfaceIntersectionSegment`
携带连接关系与保守 CHART 误差；规则交线继续使用这些类型。已有
`IntersectionVectorKind` / `IntersectionCurveKind` 的切触类别用于点和曲线。
面域重合必须有独立的关系、参数域映射和方向证据，不能编码成“曲线数为零”。
孤立接触、分叉和重合区域也不能仅改变错误码就声称被 Boolean 支持。

计算结果必须区分：已证明无交、完整规则曲线、已证明的接触/同域事件，以及未解析。
预算耗尽和未解析单元仍使整个消费者操作失败。单元、chart、周期接缝的内部表示
不得自行决定全局拓扑。空间距离只筛选候选；只有共同参与者上的有限参数和分支证据
证明相容，才合并事件，再构造和检查连接图。

### 有限域与方向

有限 edge 区间独立于基础曲线自然域；周期参数提升只能用于有限拓扑消费者，
不能改变公共曲线反求契约。face 的真实 loops、surface sense、face orientation、
coedge direction 各有自己的语义。证明用的局部 UV 图不能被当成新的人工实体 seam。

当原始曲面已经裁剪，SSI 可使用经过认证的有限域缩减；不能以采样点、局部 Newton
猜测或未经认证的包围盒跳过交支。重新参数化、旋转、镜像和尺度变化后合同相同。

### 局部操作

`set_blend → fix_blends` 先收集选边图，再按连接关系建立局部计划：独立边、光顺
边链、三价等半径角点和需要进一步拓扑事件的交汇。图的识别依赖邻接、几何连续性、
材料方向及参数区间，不依赖所选边在 body 数组中的顺序。

局部构造遵循四步：

1. 证明支撑、分支、终止和可行域；决定需要替换的 faces/edges/vertices。
2. 求解 rolling 几何、接触曲线与共同角点，明确临时几何的依赖及所有权。
3. 在共同的 `ModelingEdge` / `ModelingCoedge` / loop / face 表示中组装整个局部补片，
   检查共享边两次反向使用、有限域和材料一致性。
4. 验证后一次发布 B-rep 替换；失败通过既有 command journal 完整回滚。

光顺链上的任意拓扑分割不能改变最终几何。支撑面切换需要明确配对和公共接触点，
不能把多条共享顶点的边按固定顺序逐边圆角后当作角点处理。等半径三支持的共同
滚动球中心应由 signed offset 面的共同根认证，球角片与各 Blend 使用共享截线。
短边消失、小面消退及相邻 Blend 覆盖要有明确事件和边界更新，不能删除失败单元。

### 已验证的消费者

常规面圆角、已迁移的解析/三价圆角，以及异构滚动带使用
`SheetArrangement` 的有向有限边界和共同 halfedge/环提取；非平面 Boolean
使用同一裁剪及装配链。`ClipRegularFacePair` 将原生根隔离区间和共用事件带到
`ArrangeFaceCutGraph`，随后由 `BuildModelingBrep` 验证和发布结果。输入边的不同
拓扑身份分别保留自己的片段；已迁移的认证路径按同一事件和精确有限区间复用切割边。

重复发现同一个有限根时，见证标识实际输入边、求交方程和已经隔离的根序号；两个
coedge 各保留来源。椭圆／圆柱的标量根使用整个原生有限区间的区间包围。刀具直边／
Blend 则对 `B(u,v)−L(t)=0` 求根，在可收缩参数盒内进一步收紧结果。数学扩展域内
的根不能直接充当有限输入的交点。孤立区间重叠且无同根证据时，认证路径拒绝归并。

已支持的数学域及有限参数传递见
[有限解析滚动网络](Finite_Analytic_Rolling_Network.md)。未覆盖的通用多方事件和
实际验收差异见 [实施验收记录](reviews/advanced-modeling/topology-event-framework-acceptance.md)；
成功的自研构造、导入后操作、原始物性点值和固定探针分别记录。

## 数值与性能机制的归属

signed-normal-offset patch 是三支持角点和后续嵌套几何的共同数值原语；其位置及
Jacobian 必须向外包围，不能用差分估计替代根认证。已有 Krawczyk/区间求根继续复用。

性能统计覆盖完整 API 的阶段、候选面、SSI cell/root、预算、边界相交和 winding。
缓存只在 command 内生存，key 包含真实几何身份、generation、方向和精确参数盒；
修改、变换、回滚及跨 command 不得复用旧证据。可选缓存不能夺走原算法所需 workspace。
若无可重复的完整建模收益，应去掉额外机制，不以新增指标数量代替优化结果。

局部圆角的构造和发布会修改几何，整条命令不能默认启用不可变缓存。构造结束后的
`ValidateRegularBlendDomain` 是独立的只读证明阶段：使用真实 Blend tag/generation
建立局部 scope，退出该阶段即释放证据，再开始拓扑替换。缓存没有越过修改边界。

`ParametricPatchSeparation.CertifyDisjoint` 对两个参数盒的直积做区间细分。只有
所有叶子盒都证明某个笛卡尔坐标的严格间隙，才返回成功。全局 AABB 相交不是
几何相交；未解析、深度上限和预算耗尽也不是无交。整带间隙检查与材料查询中的
点/曲面排除共享这个机制；后者只需证明离面，无须先求到高精度的全局最近点。
整带证明保留 32,768 个累计单元预算，轻量点排除使用 2,048 个单元，未证明的点
仍进入原来的完整反求路径。真实有限平面区域还可直接通过完整边界的线性残差
同号证明与另一平面分离，避免把近乎平行的无限支持面交线强加给有限实体。

## 验证方法

- 每个支持类别先保留制造解和失败回归，再建立真正调用消费者的实体闭环。
- 自研与真实 PK 分别从相同参数构造并操作；自研 fresh XT 经 PK receive，完整
  BODY_check、拓扑、region/shell、类型、sense、容差、missing 和物性保持硬条件。
- 对边链、角点和事件族改变尺度、姿态、sense、参数化、选边顺序及拓扑分割；
  同时加入支撑域外、不可行半径、未解析和分配失败的原子回滚检查。
- M5 使用固定可复现输入记录关闭/开启优化的完整建模时间、预算与统计；不统一
  套用旧热求值 70% 指标，也不把未完成或超时运行计为通过。

本设计沿用原计划的常半径边界。变半径、任意高价角点和全部自交修复不捆绑进本轮。
每个实际交付必须列出新增支持类别、仍需拒绝的事件及其消费者证据，不能把基础
检测器、独立 sheet 或显式失败本身记为实体建模能力完成。
