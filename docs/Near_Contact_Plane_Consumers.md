# NURBS/平面近切事件到实体布尔

## 验收范围

本轮把已有强凸点接触消费者与两侧的真实事件连接起来。制造表面为 `z=.5+x²+y²`，平面为 `z=.5+h`；实体位于表面上方，工具是平面以下的方块。所有 API 分别在自研内核与真实 Parasolid 38.0.150 执行，没有向 PK 导入自研输入作为基准结果。

| h | SSI 事件 | 实体差集 | 实体交集 |
|---|---|---|---|
| `-1/64` | 无点、无曲线 | 原体 | 空 |
| `0` | 一个孤立点 | 保留实体并插入独立顶点环，9 个顶点 | 空 |
| `1/64` | 一个完整闭环 | 保留带圆形裁剪的实体 | 双面薄帽实体 |
| `2^-16`、`2^-20`、`2^-24` | 各一个完整闭环 | 同上 | 各一个双面薄帽实体 |

零高度复用已有 `PointContact`、有限双 UV 裁剪及真实顶点环消费者，见 `docs/Intersection_Point_Contact_Consumers.md`。本轮不增加点连接并集、内切空腔或有限面边界接触的支持声明。更小的 h 未纳入本轮验收。

## 公共算法改动

NURBS/平面横截求交复用已有平面标量降维：向外区间残差排空，非零区间偏导证明局部图，完整隔离边界及横截面根后连接分支。新路径将根容差设为 `2e-14`，只有严格同号的区间才排空；根容差与排空条件分开，避免把细圈附近的小残差区域混作边界。两方向均可作图时，选择按完整参数宽度缩放后下界较大的认证偏导。所有 chart 共用既有预算；未解析时在剩余预算内回退原四参数求交，耗尽明确失败。最终检查整个合并图，不能把孤立未连接节点发布为规则曲线。

自然域端点的粗根可能使后续原始 chart 截平面修正要求参数越界。只对这些端点固定边界坐标细化真实曲面的标量残差；连接区间仍在同一 Bezier span 内，且对应区间导数不含零才接纳更新。最终区间残差仍须满足 `2e-14`。没有用放宽参数域或增加 chart 密度规避端点错误。

近切交线的 Newton 求值在求两点差之前先计算齐次平面残差，使用两分量浮点运算保留小量。普通及有理、多跨曲面沿用原 knot-side、周期和 power-of-two 权重缩放规则；缩放若丢失非零分量或产生非有限值，保留原残差路径。只替换同一约束的法向分量，原 Jacobian、原始 chart 参数、双向独立追踪、UV 分辨率、物理修正量和导数一致性门槛均保留。发布前另外检查普通曲面求值所得两侧 D0 的实际空间差，稳定残差不能掩盖不可表示的输出。

实体分类首先继续使用原边界左侧见证点。分类数值失败时，可尝试外环 UV 均值作为候选；完整当前 cell 的全部 loop winding 必须证明该点在 cell 内，再重试完整实体射线分类。候选生成中的有限取点不承担材料分类或排空证明。薄帽交线再被第三平面切分时，复用已有两平面精确直线、曲面/有限线三未知根隔离及原 ICurve 参数筛支；失败继续既有四未知路径。

没有按制造模型的次数、坐标、实体 tag 或 h 值分支。核心新增代码只用栈内工作区，没有增加 C ABI。

## 可复现验证

```sh
MSBUILDDISABLENODEREUSE=1 dotnet test tests/KernelTests -c Release -p:UseSharedCompilation=false
MSBUILDDISABLENODEREUSE=1 dotnet run --no-cache scripts/ConvexPlaneContactOracle.cs -c Release
```

脚本可用 `--ssi-only` 单独跑 SSI，也可传指定高度的 invariant round-trip 字符串。输入与结果 XT 写入 `temp_docs/convex-plane-contact-oracle/`。私有 PK 依赖沿用 `scripts/ParasolidScriptHost.cs`，没有 NativeAOT 验证。

- `SplinePlaneResidualTests` 的 6 组测试用独立 BigInteger 精确二进制多项式，覆盖普通/有理、单跨/多跨、齐次权重 `2^-900` 与 `2^900`、两种世界坐标偏移。
- `NearTangentPlaneCurveTests` 的 3 组测试检查完整闭圈 D0/D1/D2、支撑残差、切向、曲率、角覆盖和闭合性；原近可分离三分支及标量求交测试继续通过。
- Oracle 对六个高度硬性要求两侧 API 成功、SSI 点/分支计数一致；闭圈逐段检查完整角覆盖和支撑残差。
- 十二个实体布尔硬性要求成功及结果数一致。每个非空结果经自研 text XT 导出、真实 PK 接收、完整 BODY_check、拓扑/region-shell/类型/sense/容差/missing 比较，并执行自研 XT 重载后同样比较。只有 chart 点数及既定内部参数化匹配项作为诊断。
- 物性比较使用十五项 `abs(self-PK)/(1+abs(PK))`，不能据此声称小体积的相对误差。另用独立解析薄帽体积 `πh²/2` 检查两侧正体积与相对误差，避免极薄实体被绝对量归一化掩盖。

验证源码基于 `3469085`，叠加 `22ff784` 与 `a0817ac`。托管 Release 的 175 项调度目录检查通过，核心 2,407 方法分配 IL 检查 CLEAN。最终原始 oracle 日志保存在 `docs/reviews/near-contact-plane-consumers-oracle.log`；它记录每个高度、操作、完整检查及严格结构差异。

最终六档 SSI、12/12 次布尔及全部非空结果重载比较通过。最大十五项归一化物性残差 `4.27e-10`，薄帽体积的解析相对误差自研小于 `7.18e-8`、PK 小于 `1.08e-7`。最细帽体体积约 `5.58e-15`，结果为 `2F/1E/0V`，没有退化为零体积成功。公共 SSI 的闭环残差最大 `1.53e-14`。

最终 KernelTests Release 全量 `1,582/1,582` 通过，零失败、零跳过。构建及测试原始输出（路径相对化）见 `docs/reviews/near-contact-plane-consumers-tests.log`。测试期间还运行了独立 PK oracle，本轮日志的操作耗时不是独占性能基准；M5 性能结果以单独的固定源码与独占计算窗口记录为准。

## 近平行第三平面的回退

完整 support-face 切换链在反射、旋转后的后续切削中暴露了一个降维错误：两支撑法向只差数个 ULP，无限平面交线的计算返回 `NumericalFailure`，原快路径却没有交还原有有限求解器。现在对这一数值状态清空临时输出计数并回退完整四参数区间证明；没有按小角度将不同平面认作平行，也没有直接返回无交。

`GeneralSheetPartitionTests.NearParallelSecondPlaneUsesCompleteFiniteIntersectionProof` 覆盖两种微小倾斜方向（`±2^-50`）。第一刀形成一个闭环，第二刀的无限平面交线在有限域之外，但曲面上产生第二个完整闭环；结果必须为 `3F/6E/4V`。与相关 sheet、近切求值及近可分离分支测试一起，14/14 通过。实际发现问题的 `SupportBlendChainOracle` 反射链已从相同输入独立执行自研与 PK，完整倒圆角、重载、布尔和全部结构硬门均通过。
