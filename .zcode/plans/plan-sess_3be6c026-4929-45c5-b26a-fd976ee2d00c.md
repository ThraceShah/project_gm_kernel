## 目标

以真实 schema（`third_party/parasolid/schema/sch_37102.sch_txt`）+ Parasolid v380 文档为权威，修正/补全内核本体（`src/ProjectGmKernel.Native/Runtime/GeometryRecords.cs`）的几何定义。**不改 `ProjectGmKernel.Xt`（XT 读写器按用户要求视为外部库），不接线 reader/writer，不做算子。**

## 重新核实后的权威事实（与上一版方案的差异）

### Blend：真实 schema 有 4 个节点（v380 文档只写了 2 个，用户判断正确）
对照 `sch_37102.sch_txt` L521-577 逐字段核实：

- **BLENDED_EDGE(56)**：`blend_type`、`surface[2]`、`spine`、`range[2]`、`thumb_weight[2]`、`boundary[2]`、`start`/`end`(LIMIT)、**`approx_spine`/`approx_spine_ctol`**（可选，文档遗漏）
- **BLENDED_VERTEX(57)**：`blend_type`、`surface[3]`、**`sub_surface[3]`**、`boundary[3]`、`range[3]`、`thumb_weight[3]`、**`centre`(v)** —— 无 spine，3 个 support
- **BLEND_OVERLAP(58)**：`surface[2]`、**`sub_surface[4]`**、`range[4]`、`thumb_weight[4]`、**`blend_type[2]`**、`overlap_type`、`swap_u_v`(logical) —— 无 spine
- **BLEND_BOUND(59)**：`boundary`(short 索引)、`blend`(反向引用)

blend_type 只有 'R'(rolling ball)/'E'(cliff edge)；chamfer 永不落盘为 blend 面（恒为 plane/cyl/cone/bsurf）；变半径/conic 不能简化时落盘为 B_SURFACE；thumb_weight 文档注明恒 [1,1]、boundary 恒 [0,0]（但字段存在，保留）。

### SP_CURVE 2D B-curve 维度（用户正确，原文确认）
xt_chap.06 §5.2.1.8：**rational → vertex 维 3（u,v,weight）；non-rational → 维 2**。SP_CURVE(137) 完整字段：`surface`、`b_curve`(2D B_CURVE)、`original`(未用)、`tolerance_to_original`(未用) + 可选 `periodic`/`class`/`chart`(SP_CHART)/`scale`/`parameter_scale`。

### 其余节点 schema 权威字段（本次逐字段核实）
- **INTERSECTION(38)**：`surface[2]`、`chart`(CHART)、`start`/`end`(LIMIT)、**`scale`**(可选，此前遗漏)、`intersection_data`(可选)。CHART(40)：base_parameter/base_scale/chart_count/chordal_error/angular_error/parameter_error[2]/hvec[](+可选扩展字段)；LIMIT(41)：type(H/T/L/B)/term_use(F/S/?)/hvec[]；INTERSECTION_DATA(204)：uv_type + values[]
- **SWEPT_SURF(67)**：`section`(曲线)、`sweep`(v 向量)、`scale` —— **无 spine**（现设计 profile+spine 错误）
- **SPUN_SURF(68)**：`profile`、`base`(v)、`axis`(v)、`start`/`end`(v 退化点)、`start_param`/`end_param`、`x_axis`(v)、`scale`
- **OFFSET_SURF(60)**：`check`(V/I/U)、`true_offset`(未用)、`surface`、`offset`、`scale`（uint/vint/u_start.../tree 为内部/可选）
- **TRIMMED_CURVE(133)**：`basis_curve`、`point_1`/`point_2`(v)、`parm_1`/`parm_2`
- **OFFSET_CURVE(46)**：`surface`、`curve`、`offset` —— **CurveClass 目前缺此类型，需补**
- **CPC(48)**：Composite parametric curve = `bezier`(段表)+`bspline`（常参数曲线是 OBSOLETE_CPC(36)）—— 现 CPCurveData 内嵌 2D 样条的设计完全错误

## 实施步骤

1. **枚举修正**：grep `parasolid_tokens.h` TYCU*/TYSU* 全部值，逐个修正 `CurveClass`（ICurve 3006→3004、SPCurve→3006、CPCurve→3008 等，补 OffsetCurve 等缺失成员）与 `SurfaceClass`；确认零运行时引用后替换 → verify: 编译 + 新增单测 hard-assert 全部枚举值等于 header token 值
2. **Blend 四件套（重点）**：`BlendSurfaceData` 删除，新建对齐 schema 的四个 record：
   - `BlendedEdgeData`：BlendType、SurfTag Surface0/1、CurveTag Spine、double Range0/1、double ThumbWeight0/1、BlendBoundTag Boundary0/1、start/end limit、CurveTag ApproxSpine + ApproxSpineCtol
   - `BlendedVertexData`：BlendType、SurfTag[3]（fixed）、SurfTag SubSurface[3]、BlendBoundTag[3]、double Range[3]/ThumbWeight[3]（fixed buffer）、KernelVector3 Centre
   - `BlendOverlapData`：SurfTag[2]、SurfTag SubSurface[4]、double Range[4]/ThumbWeight[4]、BlendType[2]、OverlapType、SwapUV
   - `BlendBoundData`：short Boundary + SurfTag Blend（反向引用）
   - 每个 record XML 注释标注 schema 节点号与字段来源、写明 'R'/'E' 语义和 cliff-edge 嵌套规则
3. **ICurveData 重设计（重点）**：SurfTag Surface0/1（恰好两个）+ 分支识别：`StartLimit`/`EndLimit`（新 `LimitRecord`：LimitType H/T/L/B + TermUse F/S/? + hvec arena offset/count）+ chart 概要（base_parameter/base_scale/chart_count + hvec arena offset）+ Scale + intersection_data 的 uv_type/values arena 引用；删除错误的"双 UV 盒"设计，注释注明 UV 参数是逐 chart hvec 的（INTERSECTION_DATA）
4. **derived/参数几何修正**：SweptData（section + sweep 向量 + scale）、SpunData（补 start/end 退化点、start/end_param、x_axis、scale）、OffsetData（补 check、scale）、TrimmedCurveData（补 Point1/Point2，TMin/TMax→Parm1/Parm2）、SPCurveData（改为 SurfTag + 2D BCurveTag + 注明 rational dim3/non-rational dim2）、CPCurveData（改为 composite parametric curve：bezier/bspline 段引用）、新增 OffsetCurveData（surface + curve + offset）
5. **单测** `tests/KernelTests/GeometryDefinitionTests.cs`：
   - 解析 `sch_37102.sch_txt` 提取上述节点的 schema 字段名集合，与各 record 的反射字段名（含 XML doc）对照，字段一一对应（AOT 主工程不受影响，测试工程可用反射）
   - 枚举 token 值与 `parasolid_tokens.h` 常量逐个断言
   - `MSBUILDDISABLENODEREUSE=1 dotnet test tests/KernelTests` 全绿（82+新增）；Xt.Tests、corpus `--check` 不受影响（本次零 codec 改动）
